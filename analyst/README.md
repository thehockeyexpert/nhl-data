# Golden questions

Example questions with known correct answers, used to check the conversational query layer.
- `golden_questions.yml`: the questions, with definitions and the owner's original wording.
- `golden_answers.md`: reference answers by direct SQL (2026-11-13), to compare a blind run against.
- `publish_guide.py`, `claude_project_instructions.md`: the MotherDuck guide and the Claude.ai Project's short note.
- `question_inbox.md`: the owner's question list (git-ignored, laptop only).
